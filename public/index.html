What is GojoClaw?

GojoClaw is an advanced autonomous AI assistant built on the next-generation Google ADK 2.0 (Agent Development Kit) framework and powered by Gemini AI. It provides personal assistant capabilities natively across multiple messaging channels while maintaining full context memory.

Capabilities & Tools

💻

Shell Access

Execute shell command lines securely in local environments with restricted fallback sandboxing in the cloud.

📁

File Operations

Read, write, list, and delete files. Automatically redirects to a secure writable sandbox on cloud systems.

🌐

Web Browsing

Retrieves web pages, filters out HTML tags, and reads documentation or web articles directly.

📧

Email Summaries

Connects via Google OAuth2/credentials to list and summarize your unread Gmail messages.

💬

Multi-Channel

Handles Telegram, Discord, and WhatsApp integrations concurrently with partitioned chat sessions.

🧠

Persistent Memory

Saves conversation history to local JSON files so context is never lost during agent restarts.
